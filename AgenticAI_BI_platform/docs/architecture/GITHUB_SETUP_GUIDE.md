# GitHub Artifacts Setup Guide

## Quick Start

### 1. Create GitHub Repositories

Create these 5 repositories on GitHub:

```bash
# Option 1: Using GitHub CLI
gh repo create business-inception-artifacts --private --description "Business Problem Inception Reports"
gh repo create business-glossary-artifacts --private --description "Business Glossary Terms and Definitions"
gh repo create metadata-objects-artifacts --private --description "Conceptual Business Elements and Metadata Objects"
gh repo create data-vault-artifacts --private --description "Data Vault Modeling Artifacts (Hubs, Links, Satellites)"
gh repo create bi-reports-artifacts --private --description "Business Intelligence Reports and Analysis"

# Option 2: Using GitHub Web UI
# Go to https://github.com/new and create each repository manually
```

### 2. Generate GitHub Personal Access Token

1. Go to GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click "Generate new token (classic)"
3. Give it a name: "Agentic BI Artifact Service"
4. Select scopes:
   - ✅ `repo` (Full control of private repositories)
5. Generate token and **copy it immediately** (you won't see it again)

### 3. Configure Environment Variables

Add to your `.env` file:

```env
# GitHub Configuration
GITHUB_TOKEN=your_personal_access_token_here
GITHUB_OWNER=your-github-username

# Repository Names (optional - defaults provided)
GITHUB_REPO_INCEPTION=business-inception-artifacts
GITHUB_REPO_GLOSSARY=business-glossary-artifacts
GITHUB_REPO_METADATA=metadata-objects-artifacts
GITHUB_REPO_DATA_VAULT=data-vault-artifacts
GITHUB_REPO_BI_REPORTS=bi-reports-artifacts
```

### 4. Initialize Repository Structure

For each repository, create the initial structure:

```bash
# Clone each repo
git clone https://github.com/your-username/business-inception-artifacts.git
cd business-inception-artifacts

# Create directory structure
mkdir -p artifacts/2025/.github/workflows
mkdir -p metadata

# Create README.md
cat > README.md << 'EOF'
# Business Inception Artifacts

This repository contains Business Problem Inception Reports generated by the Agentic AI BI Platform.

## Structure

- `artifacts/` - Organized by year and month
- `metadata/` - Index files and metadata

## Usage

Artifacts are automatically created and pushed by the Inception Agent workflow.
EOF

# Commit and push
git add .
git commit -m "Initial repository structure"
git push origin main
```

Repeat for each repository with appropriate structure.

## Integration with n8n Workflows

### Option 1: HTTP Request Node

Add an HTTP Request node to your n8n workflow:

**Node Configuration**:
- Method: `POST`
- URL: `http://your-backend:8000/api/github/push-artifact`
- Body:
```json
{
  "artifact_type": "inception",
  "session_id": "{{ $json.session_id }}",
  "content": "{{ $json.content }}",
  "workflow_id": "{{ $workflow.id }}"
}
```

### Option 2: Direct GitHub API Node

Use n8n's GitHub node to push directly:

1. Add GitHub node
2. Configure with your token
3. Operation: "Create or Update File"
4. Repository: `business-inception-artifacts`
5. File Path: `artifacts/2025/01-january/inception-{{ $json.session_id }}.md`
6. Content: `{{ $json.content }}`

## API Endpoints

The service can be exposed via FastAPI endpoints (see `github_artifact_routes.py`):

- `POST /api/github/push-inception` - Push inception artifact
- `POST /api/github/push-glossary` - Push glossary term
- `POST /api/github/push-metadata` - Push metadata object
- `POST /api/github/push-data-vault` - Push data vault artifact
- `POST /api/github/push-bi-report` - Push BI report

## Troubleshooting

### Error: "GITHUB_TOKEN environment variable is required"
- Make sure you've added `GITHUB_TOKEN` to your `.env` file
- Restart your backend service after adding the token

### Error: "Repository not found"
- Check that `GITHUB_OWNER` matches your GitHub username
- Verify repository names match exactly (case-sensitive)
- Ensure the token has `repo` scope

### Error: "Bad credentials"
- Regenerate your GitHub token
- Make sure the token hasn't expired
- Verify the token has the correct scopes
