# n8n Workflow: Create GitHub Repositories

## Overview
This workflow automatically creates all 5 GitHub repositories needed for artifact storage.

## Setup Instructions

### 1. Import the Workflow

1. Open your n8n instance
2. Click **"Workflows"** → **"Import from File"**
3. Select `n8n-workflows/create-github-repos-workflow-v2.json`
4. The workflow will be imported with all nodes

### 2. Configure GitHub Credentials

You need to set up HTTP Header Auth credentials for GitHub:

1. In n8n, go to **Credentials** → **New Credential**
2. Select **HTTP Header Auth**
3. Configure:
   - **Name**: `GitHub Token`
   - **Name**: `Authorization`
   - **Value**: `token YOUR_GITHUB_PERSONAL_ACCESS_TOKEN`
   
   **Important**: The format must be `token YOUR_TOKEN` (not just the token)

4. Save the credential

### 3. Update Workflow Nodes

After importing, you'll need to:

1. **Select each "Create [X] Repo" node** (5 nodes total)
2. **Click on the credential dropdown**
3. **Select "GitHub Token"** (the credential you just created)
4. **Save the workflow**

### 4. Configure Repository Owner (Optional)

If you want to create repos under an organization instead of your user account:

1. Update the URL in each HTTP Request node from:
   ```
   https://api.github.com/user/repos
   ```
   to:
   ```
   https://api.github.com/orgs/YOUR_ORG_NAME/repos
   ```

### 5. Execute the Workflow

1. Click **"Execute Workflow"** button
2. The workflow will:
   - Create all 5 repositories in parallel
   - Collect results
   - Show you the repository URLs

## Troubleshooting

### Error: "Bad credentials"
- Check that your GitHub token is valid
- Ensure the token has `repo` scope
- Verify the credential format is `token YOUR_TOKEN`

### Error: "Repository already exists"
- The repository with that name already exists
- Either delete it first or modify the workflow to use different names
- You can add error handling to skip existing repos

### Error: "Not Found" when using org
- Verify the organization name is correct
- Ensure your token has permission to create repos in that org
- Check that you're a member/admin of the organization

### Repos created but workflow shows errors
- Check individual node execution logs
- Some repos may have been created successfully even if others failed
- Check your GitHub account to see which repos were created
